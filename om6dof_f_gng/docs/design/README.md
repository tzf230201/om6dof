# Rencana pengembangan F-GNG

Dokumen utama adalah [`BIO_INSPIRED_FOVEATION.md`](BIO_INSPIRED_FOVEATION.md).
Dokumen itu memisahkan seleksi fiksasi, sampling retinotopik, akomodasi virtual,
visibilitas, serta integrasi graph dalam koordinat dunia.

[`FOVEATION_V2_DESIGN.md`](FOVEATION_V2_DESIGN.md) adalah rancangan sebelumnya.
Ia disimpan untuk riwayat keputusan, tetapi aturan nearest-surface dan mask
geodesiknya sudah digantikan oleh rancangan bio-inspired utama.

Naskah paper berada di [`../../paper/icra2027_fgng/`](../../paper/icra2027_fgng/).
Hasil numerik paper saat ini mendahului beberapa perubahan package ROS terbaru;
hasil baru tidak boleh dimasukkan tanpa menjalankan ulang protokol evaluasi.
