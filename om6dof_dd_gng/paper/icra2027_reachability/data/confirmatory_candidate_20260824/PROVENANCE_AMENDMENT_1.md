# Confirmatory provenance amendment 1

Date: 2026-08-25 JST

This amendment was made before catalog creation and before observing any
confirmatory benchmark outcome.

The frozen checklist supplied the expanded-URDF SHA-256
`485617d99a2483abd6327b03bb6d3a0a52f71be08adba6234343e1e4a1cd328a`.
That digest was produced by invoking xacro through the AGX source path. The
frozen launch invokes the same symlinked xacro through its installed package
path and therefore reports
`daf37611724f4c8efd69b3b470bf505cfce4732353ea985ec54fbbb01f6d412d`.

A byte-level diff of both expanded URDFs found exactly one difference: xacro's
autogenerated comment names the source input path as `src/...` in the first
file and `install/...` in the second. After removing that comment line, both
files have the identical SHA-256
`d1a61a3e87209c44c7ed8386f40fd831c8ddcdda759dacdea05b3890b05f6d7e`.
Robot links, joints, limits, geometry, and parameters are identical.

Operational resolution: use the runtime-reported installed-path digest
`daf37611724f4c8efd69b3b470bf505cfce4732353ea985ec54fbbb01f6d412d`
for catalog generation and the benchmark runtime contract. No algorithm,
parameter, scene, stream, or analysis setting was changed.
